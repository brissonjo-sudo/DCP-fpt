Remarques pour le skill (applicabilité) :
- Pour une collectivité territoriale, le seuil de procédure formalisée pour fournitures et services est celui des « autres pouvoirs adjudicateurs », pas celui des autorités publiques centrales (État). Une confusion entre les deux est une erreur de procédure (valeurs en « Valeurs relevées »).
